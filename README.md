# AutoChina Marketplace

Приложение для продажи автомобилей из Китая с полной разбивкой стоимости.

## Стек
- **Backend**: Python · FastAPI · SQLite
- **Frontend**: React · Vite · Tailwind CSS

## Запуск

### Бэкенд
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
API доступен на http://localhost:8000

### Фронтенд (разработка)
```bash
cd frontend
npm install
npm run dev
```
Сайт доступен на http://localhost:5173

### Продакшн (фронтенд → бэкенд)
```bash
cd frontend && npm run build
cd ../backend && uvicorn main:app
```

## Доступы
- **Сайт**: http://localhost:5173 (или :8000 в продакшн)
- **Админка**: http://localhost:5173/admin · пароль по умолчанию: `china2024`

## Функции
| | |
|---|---|
| Каталог | Все авто с фильтрами (марка, год, тип двигателя, цена, статус) |
| Карточка авто | Фото-галерея, характеристики, полная разбивка цены, трекер доставки |
| Разбивка цены | Цена в Китае, доставка, пошлина, сбор, СБКТС, утилизационный сбор, комиссия |
| Калькулятор | Расчёт для любого авто по объёму, году и цене в Китае |
| Статус | в Китае → в пути → в Новороссийске → на таможне → готова к выдаче |
| Админка | Добавление/редактирование авто, загрузка фото, настройка курсов и ставок |
